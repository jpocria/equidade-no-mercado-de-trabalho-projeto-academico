# Equidade no Mercado de Trabalho - A3

Projeto da disciplina **Algoritmos e Programação**, do Centro Universitário UNA.

**Integrantes:** João Pedro Antunes e Tulio Amaral  
**Tema:** analisador de anúncios de vaga para identificação de termos potencialmente excludentes ou discriminatórios.

## O que o projeto pretende fazer

O programa receberá o texto de um anúncio de vaga e procurará expressões que merecem revisão. Para cada sinal encontrado, apresentará a categoria, uma explicação simples e uma sugestão de redação mais objetiva.

O resultado será apenas educativo e preventivo. A ferramenta não determina que uma vaga ou empresa praticou discriminação e não substitui avaliação humana ou jurídica.

## Organização

O trabalho foi dividido em sete fases internas:

1. E1 - documento de pesquisa (entregável oficial).
2. E2 - fluxograma (entregável oficial).
3. Checkpoint de código preliminar (etapa formativa).
4. E3 - código-fonte (entregável oficial).
5. Testes e ajustes (etapa interna).
6. E4 - relatório final (entregável oficial).
7. E5 - apresentação e demonstração (entregável oficial).
